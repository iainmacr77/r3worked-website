The standard section header pattern used above every homepage section: a small coral eyebrow label, a large `type-h2` title, and a supporting paragraph. Works on both light and dark sections via `dark`.

```jsx
<SectionHeading
  eyebrow="The System"
  title={<>The <span style={{color:'var(--r3-coral)'}}>3</span> in R3WORKED.</>}
  description="Three practical layers that make your website look better, capture more enquiries, and help you stay on top of them."
/>
```
