The R3WORKED wordmark — there is no separate logomark/icon in this brand; the "3" set in coral inside the wordmark IS the brand device. Always render as text (not an image) so it inherits weight/tracking correctly at any size.

```jsx
<Wordmark size="1.1rem" />          {/* nav */}
<Wordmark size="1.45rem" />         {/* footer, larger */}
```
